 🎯 Objective
Analyze loan portfolio data to identify **risk categories, KPIs, and financial insights** using SQL queries.

---

 📂 Contents
- **Basic Queries** → Customer & loan details  
- **Filtering & Sorting** → Conditions, ranges, ordering  
- **Aggregates** → SUM, AVG, MIN, MAX, COUNT  
- **Group By & Having** → Loan type, city, state, employment  
- **Risk Classification** → CASE statements for credit score categories  
- **Business KPIs** → Approval rate, rejection rate, overdue loans  
- **Date Analysis** → Applications, approvals, disbursements by year/month  
- **Subqueries** → Compare with averages, find top records  
- **Advanced Analysis** → Multi‑loan customers, high loan‑to‑income ratio, defaults  

---

 📊 Key Highlights
- Classified borrowers into **Low, Medium, High, Very High Risk** based on credit score.  
- Calculated **Loan Approval Rate, Rejection Rate, Overdue Loan %**.  
- Identified **top customers, cities, and loan types** by disbursement and outstanding amounts.  
- Detected **high‑risk borrowers** with low credit scores and high overdue balances.  

---

 🛠️ Skills Used
- SQL: `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`  
- Aggregate functions: `SUM`, `AVG`, `MIN`, `MAX`, `COUNT`  
- Conditional logic: `CASE` statements  
- Subqueries & Joins for advanced analysis  

---

 🚀 How to Use
1. Import the `Loan` table dataset into your SQL environment.  
2. Run queries sequentially (Q1–Q80) to explore different aspects of loan portfolio risk.  
3. Adjust thresholds (loan amount, credit score, overdue limits) to fit other datasets.
